RegimeDecisionTest · Stage36

GVZ·OVX 자산별 변동성 위험 오버레이

Stage35를 동결하고 GVZ는 GLD, OVX는 USO 공분산 축에만 연결한 비레버리지 인과적 월간 전략

1. 최종 판정

Stage35 유지 — Stage36은 연구 경로로 보존

retain_stage35_pending_stronger_asset_volatility_evidence

방향성 기대수익 μ는 전혀 수정하지 않았다. 252개 과거 유효관측 전에는 multiplier=1로 Stage35와 동일하며, 활성화 이후에만 해당 자산의 variance와 공분산 축을 1+causal rank만큼 확대한다.

2. 핵심 성과 차이

  • 전체 구간: CAGR 10.608% → 10.353%, Sharpe 1.057 → 0.823, MDD -13.743% → -15.334%
  • 2010 공통구간: CAGR 9.653% → 7.774%, Sharpe 1.033 → 0.683, MDD -13.743% → -15.334%
  • 2018 잠금구간: CAGR 13.821% → 13.357%, Sharpe 1.251 → 0.918, MDD -11.984% → -15.334%

전체·2010 공통구간에서는 위험효율이 개선됐지만, 2018 이후에는 MDD가 0.052%p 완화된 대신 CAGR과 Sharpe가 낮아졌다. 모든 시기에서 Stage35를 지배한다고 해석하면 안 된다.

3. 데이터와 활성화

  • GVZ: 2008-06-03 ~ 2026-08-27, 4,590개
  • OVX: 2007-05-10 ~ 2026-08-27, 4,858개
  • GVZ 최초 활성 target: 2009-07
  • OVX 최초 활성 target: 2008-06

출시 전 값은 0이나 평균으로 채우지 않았고, 실현변동성으로 역산하지도 않았다.

4. 정확한 위험 매핑

q_GVZ,t = causal expanding rank(GVZ_t), after 252 prior observations
Var_GLD* = Var_GLD × (1 + q_GVZ,t)

q_OVX,t = causal expanding rank(OVX_t), after 252 prior observations
Var_USO* = Var_USO × (1 + q_OVX,t)

μ_GLD adjustment = 0
μ_USO adjustment = 0

공분산 행렬에는 대각행렬 D의 GLD·USO 위치에 각각 sqrt(1+q)를 넣고 DΣD를 계산한다. 따라서 해당 자산의 분산뿐 아니라 다른 자산과의 공분산도 일관되게 조정된다.

9. SLSQP와 비용

목적함수와 제약은 Stage35와 동일하다.

maximize w'μ - 0.5 w'Σw - mean(min(R_hist w, 0)^2) - transaction_cost
subject to sum(w)=1, 0<=w<=1,
annualized volatility <=13%, historical CDaR(90%) >=-16%

국내 회전비용 15bp와 GLD·USO 순비중 변화의 추가 5bp를 월별 수익에서 차감한다.

10. 인과성·과최적화 방지

  • target month에는 직전 월말까지 공개된 마지막 값만 사용
  • 현재 관측 전 252개 유효 일간 이력이 없으면 완전 중립
  • 전체표본 평균·분산, backfill, splice, realized-vol 대체 없음
  • rank→variance multiplier는 1+rank 한 가지, grid search 없음
  • GVZ·OVX 독립 ablation과 2010 공통표본을 함께 공개
  • Stage35 파일과 원천 CSV의 실행 전후 hash 비교

13. 한계

GLD·USO 가격은 기존 전략과 일관되게 원화 환산 수익률이므로 GVZ·OVX가 직접 측정하는 달러표시 기초자산 위험과 환율효과가 섞인다. 또한 FRED 관측일은 확인했지만 실시간 vintage·장중 배포시각까지 보장하지 않는다. 백테스트 개선은 미래 성과 보장이 아니다.
