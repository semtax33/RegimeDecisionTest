# Stage 23 — 상대 ATR 공분산

`1 + ATR 백분위`를 네 자산 평균으로 나눠 평균 분산 배율을 1로 고정한다. 절대 위험회피도를 올리지 않고 자산 간 상대 위험만 반영하는 단일 변경이다.

| 구간 | CAGR | Sharpe | MDD |
|---|---:|---:|---:|
| 2007-04~2026-07 | 9.6412% | 0.8661 | -16.1238% |
| 2018-01~2026-07 | 13.0459% | 1.1181 | -15.7097% |

CAGR은 0.24%p 올랐지만 위험예산이 과도하게 풀려 Sharpe와 MDD가 모두 악화됐다. 기각한다. 코드는 `relative_atr_slsqp.py`, 결과는 `outputs/relative_atr_monthly.csv`에 있다.
