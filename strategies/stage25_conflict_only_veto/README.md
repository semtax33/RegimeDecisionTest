# Stage 25 — 전 자산 충돌 시 기술적 거부권

기술신호가 거시전망과 일치하거나 중립이면 거시 기대수익을 보존하고, 방향이 충돌할 때만 신호 크기만큼 축소한다. 별도의 문턱값이나 계수는 없다.

| 구간 | CAGR | Sharpe | MDD |
|---|---:|---:|---:|
| 2007-04~2026-07 | 10.1253% | 0.9750 | -17.7915% |
| 2018-01~2026-07 | 14.0631% | 1.2504 | -11.2866% |

CAGR 10%는 넘었지만 채권 비중이 크게 줄어 전체 MDD가 3.78%p 악화됐다. 목표 세 조건을 동시에 충족하지 못해 기각한다. 코드는 `conflict_only_veto_slsqp.py`, 결과는 `outputs/conflict_only_veto_monthly.csv`에 있다.
