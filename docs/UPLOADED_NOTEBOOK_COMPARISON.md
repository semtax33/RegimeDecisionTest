## 업로드 노트북의 알고리즘

### 1. 입력변수

- 성장: GDP YoY 72개월 z-score, 수출 YoY 36개월 z-score, 제조업 업황전망 BSI 24개월 z-score
- 물가: CPI YoY 36개월 z-score, PPI YoY 36개월 z-score, 수입물가 YoY 48개월 z-score
- 성장점수 `g`: 성장 변수 세 개의 단순평균
- 물가점수 `i`: 물가 변수 세 개의 단순평균

각 z-score는 ±3으로 자릅니다. 별도의 학습이나 회귀는 없습니다.

### 2. 국면 분류

성장점수와 물가점수 각각에 상단 `+0.2`, 하단 `-0.2` 히스테리시스를 적용합니다. 점수가 중립 구간에 들어오면 직전 상태를 유지하고 경계를 넘어갈 때만 상태를 바꿉니다.

| 성장 상태 | 물가 상태 | 국면 | 목표 비중 |
|---|---|---|---|
| 상승 | 하락 | Goldilocks | KODEX200 100% |
| 상승 | 상승 | Overheating | USO 100% |
| 하락 | 하락 | Slowdown | KODEX200 60% + 국내채권 40% |
| 하락 | 상승 | Stagflation | GLD 100% |

월말에 확인한 국면으로 다음 달 첫 거래일에 리밸런싱하고, 다음 달 첫 거래일까지 보유합니다. 거래비용은 자산 매매 15bp, 달러 자산 순비중 변화에는 환전비용 5bp를 적용합니다.

## 현재 전략과 구조적으로 다른 점

| 항목 | 업로드 노트북 | 현재 Robust VKOSPI |
|---|---|---|
| 국면 표현 | ±0.2 히스테리시스의 Hard 상태 | 무SJM 확률형 성장·물가 상태 |
| 기본 비중 | 국면별 고정 비중, 최대 단일자산 100% | Hard 40% + SLSQP 연속 최적화 60% |
| 꼬리위험 예측 | 없음 | 16개 입력의 균형 L2 로지스틱 |
| 추가 입력 | 없음 | 일별 모멘텀·변동성·상관, OAP 합성변수 4개 |
| 공포지수 | 없음 | VKOSPI 수준·충격·가속도 일간 오버레이 |
| 위험 제어 | 히스테리시스만 사용 | 목표변동성, 꼬리위험 이동, VKOSPI 방어 이전 |
| 옵션/VIX6 | 미사용 | 검증했지만 강건성 관문 실패로 최종 비중 0% |

업로드 노트북의 강점은 단순성과 높은 상승장 노출입니다. 약점은 국면 오분류 시 100% 집중 포지션이 그대로 손실로 이어지고, 국면 확률이나 일별 스트레스에 따라 위험을 연속적으로 줄이는 장치가 없다는 점입니다.

## 재현 방법과 주의점

노트북에 저장된 원래 출력은 2006-05–2026-07, 243개월 기준 CAGR 18.63%, Sharpe 0.868, MDD -25.25%입니다. 현재 전략은 24개월 워밍업 때문에 2007-04부터 시작하므로, 본문 표는 두 전략을 같은 2007-04–2026-07로 맞췄습니다.

비교는 다음 두 방식으로 교차 확인했습니다.

1. 업로드 노트북을 로컬 원자료와 당시 코드로 직접 재실행: CAGR 20.47%, Sharpe 0.929, MDD -25.25%.
2. 노트북의 국면 라벨·고정 비중을 프로젝트 공통 시장 캐시와 비용 엔진에 입력: CAGR 20.46%, Sharpe 0.929, MDD -25.25%.

두 결과가 거의 같아 전략 비교에는 충분하지만, 노트북의 `yfinance period="max"` 호출은 실행 시점에 따라 KODEX200 과거 구간을 충분히 내려받지 못할 수 있습니다. 저장된 실행에서는 실제 KODEX200 ETF의 첫 사용일이 2026-07-22로 잡혀, 의도했던 2009-04 전환 대신 KOSPI200 프록시가 대부분의 기간에 사용됐습니다. 재현 가능한 비교에서는 프로젝트의 고정 시장 캐시를 사용하는 편이 안전합니다.

또한 2026년에는 양쪽 입력 데이터에 절댓값 20%를 넘는 월수익이 여러 차례 포함됩니다. 그래서 2025-12까지의 민감도 결과도 함께 제시했습니다. 결론은 같았습니다. 업로드 노트북은 CAGR이 높고, 현재 전략은 Sharpe와 MDD가 우수합니다.

마지막으로 현재 무SJM 경로 역시 여러 후속 실험에서 2018년 이후를 이미 본 post-lock 비교선입니다. 위 표는 계산상 비교이지, 두 전략 가운데 하나가 완전한 미관측 홀드아웃에서 우월하다는 통계적 증명은 아닙니다.
