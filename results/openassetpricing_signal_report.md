# Open Asset Pricing 기반 국내 전략 입력변수 실험

## 결론

[Open Asset Pricing SignalDoc Browser](https://openassetpricing.com/SignalDoc-Browser.html)의 가격·거래량 신호를 KRX 업종지수 횡단면에 맞게 번역해 테스트했다. 현재 로컬 데이터로 재현 가능한 신호만 사용했으며, 회계·애널리스트·옵션·공매도 신호는 시점별 원자료가 없어 제외했다.

가장 균형 잡힌 후보는 다음과 같다.

`기존 FinalBlend 자산배분 + OAP 2개월 경로손실 오버레이 + 15% 변동성 타기팅`

- 목표: 향후 2개월 중 누적 경로손실이 -5% 아래로 내려갈 위험.
- 입력: 국내 기본 변수 + OAP 기반 모멘텀·반전/쏠림·저위험/꼬리·유동성 합성지표.
- 학습: balanced logistic, 2개월 label embargo.
- 실행: 위험확률의 과거 확장 백분위가 80% 이상일 때만 비대칭 방어.
- 방어 이동 한도: 20%.
- 선택: 2017년까지 기존 전략의 CAGR, Sharpe, MDD를 모두 개선한 2~3개월 후보만 허용한 뒤 Calmar, Sharpe, CAGR 순으로 결정.
- 잠금 검증: 2018-01 이후 자료는 입력변수, 목표기간, 임계값, 이동 한도 선택에 사용하지 않음.

## OAP 신호의 국내 업종지수 번역

| 합성지표 | SignalDoc 아이디어 | 국내 구현 |
|---|---|---|
| 모멘텀·추세 | Mom12m, Mom6m, IntMom, High52, IndMom, MomVol | 업종 12/6/중기 모멘텀 중앙값, 52주 고점 거리, 상승 업종 비율, 거래대금 가중 업종 모멘텀 |
| 반전·쏠림 | STreversal, MRreversal, LRreversal | 업종 단기·중기·장기 수익률 중앙값과 단기/12개월 횡단면 분산 |
| 저위험·꼬리 | RealizedVol, IdioVol3F, MaxRet, ReturnSkew, Beta | 업종 실현변동성, 시장회귀 잔차변동성, 월중 최대 일수익률, 왜도, 베타 평균·분산 |
| 유동성·활동 | Illiquidity, DolVol, VolumeTrend, VolSD | `절대수익률/(지수×거래량)` Amihud 대용치, 거래대금 z-score, 60개월 거래량 추세, 36개월 거래량 변동계수 |

모든 일별 값은 목표 월 시작 최소 2일 전까지만 사용했다. 월별 표준화는 현재 월을 제외한 직전 60개월로 계산했다. SignalDoc에서 Placebo 또는 Dropped로 분류한 DownsideBeta와 수익률 일관성 신호는 사전에 제외했다.

이 구현은 미국 개별주 신호의 정확한 복제가 아니라 국내 업종지수 기반 거시·시장상태 아날로그다.

## 기존 전략과의 합성 결과

정상 거래비용, 전체 2007-04~2026-07, 잠금 2018-01~2026-07:

| 전략 | 잠금 CAGR | 잠금 Sharpe | 잠금 MDD | 전체 CAGR | 전체 Sharpe | 전체 MDD |
|---|---:|---:|---:|---:|---:|---:|
| FinalBlend | 17.07% | 1.164 | -14.90% | 14.30% | 1.024 | -14.90% |
| 기존 구조 + Vol15 | 17.74% | 1.196 | -12.56% | 14.85% | 1.050 | -13.04% |
| 기존 구조 + 지수거래량 + Vol15 | 17.75% | 1.210 | -12.95% | 14.90% | 1.060 | -13.60% |
| 구조·지수거래량·OAP 공동학습 + Vol15 | 17.74% | **1.212** | -12.65% | 14.92% | **1.061** | -13.19% |
| **선택: OAP 2개월 경로손실 + Vol15** | **17.86%** | 1.211 | **-12.56%** | **14.95%** | 1.059 | **-12.98%** |
| OAP 위험위원회(CAGR형) | 17.83% | 1.186 | -12.99% | 15.14% | 1.053 | -13.06% |

선택된 중기 OAP 오버레이는 MDD 우선 기준인 `기존 구조 + Vol15` 대비 세 지표를 모두 개선했다.

| 구간 | CAGR 변화 | Sharpe 변화 | MDD 변화 |
|---|---:|---:|---:|
| 캘리브레이션 2007-2017 | +0.07%p | +0.005 | +0.06%p |
| 잠금 2018-2026 | +0.12%p | +0.015 | 동일 |
| 전체 2007-2026 | +0.09%p | +0.009 | +0.06%p |

`기존 구조 + 지수거래량 + Vol15`와 비교하면 잠금 CAGR +0.11%p, Sharpe +0.001, MDD +0.39%p이고, 전체 CAGR +0.05%p, Sharpe -0.0001, MDD +0.61%p다. 즉 지수거래량 버전보다 Sharpe는 사실상 동일하면서 낙폭이 작다.

단순 확률 선형합성은 기존 위험신호를 희석해 CAGR과 Sharpe가 낮아졌다. 기존 구조·지수거래량·OAP 모델 중 가장 낮은 위험도를 쓰는 합의형 위원회는 전체 CAGR을 15.14%로 높였지만 잠금 Sharpe와 MDD가 악화되어 CAGR 우선 보조 후보로만 남겼다.

## 하위 기간

| 기간 | 기존 구조+Vol15 CAGR / Sharpe / MDD | 선택 OAP CAGR / Sharpe / MDD |
|---|---:|---:|
| 2007-2012 | 22.87% / 1.296 / -11.44% | 22.43% / 1.270 / -12.98% |
| 2013-2017 | 1.85% / 0.271 / -10.68% | 2.41% / 0.344 / -10.68% |
| 2018-2021 | 10.95% / 0.853 / -12.56% | 11.14% / 0.891 / -12.56% |
| 2022-2026 | 24.00% / 1.461 / -11.78% | 24.05% / 1.453 / -11.37% |

2007-2012에는 기존 구조 전략보다 나빴고, 이후 세 구간에서는 대체로 CAGR 또는 MDD가 개선됐다. 따라서 모든 시장 국면에서 우월한 신호는 아니다.

## 비용 강건성

정상 비용의 3배에서도 선택 OAP 전략은 기존 구조+Vol15 대비 세 지표가 모두 높거나 같았다.

| 전략 | 전체 CAGR | Sharpe | MDD | 잠금 CAGR | Sharpe | MDD |
|---|---:|---:|---:|---:|---:|---:|
| 기존 구조 + Vol15 | 13.84% | 0.988 | -13.84% | 16.53% | 1.123 | -12.78% |
| 선택 OAP 2개월 + Vol15 | **13.90%** | **0.995** | **-13.02%** | **16.55%** | **1.132** | -12.78% |

## 통계적 주의점

- 잠금 구간 6개월 블록 부트스트랩에서 기존 구조+Vol15보다 Sharpe가 높을 확률은 73.5%였다.
- Sharpe 차이의 5~95% 구간은 -0.040~+0.094로 0을 포함한다.
- 선택 모델의 캘리브레이션 예측 AUC는 0.379, 잠금 AUC는 0.757이었다. 캘리브레이션 희귀사건이 9건뿐이어서 예측력 자체는 불안정하다.
- 여러 후보를 비교했으므로 성과 차이를 확정적 알파로 해석하면 안 된다.

따라서 백테스트상 다목적 개선은 달성했지만, 통계적으로 확정된 개선은 아니다. 실전 적용 전에는 설정을 고정한 전진 관찰이나 별도 시점별 개별종목 데이터 검증이 필요하다.

## 권고안

- 균형형 기본 후보: `SelectedMediumHorizonOAPVol15`.
- 최대 Sharpe 우선 후보: `JointStructureIndexVolumeOAPVol15`.
- 최대 CAGR 우선 후보: `CalibratedOAPRiskCommittee`.
- 단순 선형 위험확률 합성은 사용하지 않는다.
- 회계 기반 OAP 신호는 시점별 KOSPI200 구성종목과 재무제표가 확보되기 전까지 추가하지 않는다.
